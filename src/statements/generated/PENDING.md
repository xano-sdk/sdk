## Byte-level evidence is not tracked here

A generated spec is a reading of the engine's SCHEMA, which says what the engine
declares. Whether this SDK emits what the engine PERSISTS is a different
question, and it is measured elsewhere:

- `npm run audit:decode-coverage -- <sweep-dir>` — which statements a corpus of
  real workspaces proves, by re-encoding each stored instance.
- `src/statements/byte-evidence.ts` — the statements no workspace stores, and
  which of those a live round trip proved instead.

This file used to report a `fixture-proven` / `registered but unproven` split.
It was removed rather than reworded because it did not measure what it named: it
reported which fixtures one codegen run happened to see in `XANO_FIXTURE_DIR`,
which is a fact about that run's inputs. Read as a byte-fidelity backlog it named
112 statements, of which 82 were already proven many times over by the corpus.
Do not reintroduce it.
