# AI statements

> Read when the stack calls `s.ai.*` (a Xano AI model, an external MCP server) or you choose where a Xano AI call runs.

On the Xano AI model statements, `model` takes any string and autocompletes the known models; the suggestions come from a snapshot and can lag. For the current list, what each model allows and where it can run, run `npx @xano/sdk ai models --json` (`--all` adds unlisted models). It keys `statements` by short name: `text`→`s.ai.text.generate`, `image`→`s.ai.image.generate`, `video`→`s.ai.video.generate`, `music`→`s.ai.music.generate`, `speech`→`s.ai.speech.generate`, `transcribe`→`s.ai.speech.transcribe`, `embedding`→`s.ai.embedding.create`, `rerank`→`s.ai.rerank`; `agent.models` are the `xano-ai` agent models. Leave `model` out to run the statement's default. `s.ai.text.generate` needs `prompt` or `messages`. ⚠ `save_to_files` on `s.ai.video.generate`, `s.ai.music.generate` and `s.ai.speech.generate` needs a paid plan (`s.ai.image.generate` does not).

- **Where a call runs (`location`)**, on these statements and on a `xano-ai` agent: its own `location` wins; blank inherits the workspace's Xano AI location; blank there too sends none, and the gateway runs the model at its default. An explicit `"global"` opts out of a workspace `"eu"`. A statement refuses, before sending anything, a location its model cannot run at (the model's `locations` in `ai models`); an agent's location is refused by the gateway instead.
- **The workspace's Xano AI location:** `workspaceConfig({ settings: { ai_settings: { providers: { "xano-ai": { location: "eu" } } } } })`, `"" | "us" | "global" | "eu"`, lowercase (anything else THROWS). A deploy that omits the `xano-ai` block keeps the live location; an empty block or `location: ""` clears it. A merge (`deploy --to`) writes no workspace settings, and `--branch <label>` leaves them alone.

- `s.ai.agent.run` [special]
- `s.ai.embedding.create({ as?: string; model?: value; input: value; task_type?: value; dimensions?: value; location?: "" | "us" | "global" | "eu" })` → as: { embeddings: number[][]; model: string; usage: { input_tokens?: number; output_tokens?: number } } (one vector per input, in input order; a single input still binds a list of one — read embeddings[0])
- `s.ai.external.mcp.server_details({ as?: string; url: value; bearer_token?: value; connection_type?: "sse" | "stream" })`
- `s.ai.external.mcp.tool.list({ as?: string; url: value; bearer_token?: value; connection_type?: "sse" | "stream" })`
- `s.ai.external.mcp.tool.run({ as?: string; url: value; bearer_token?: value; connection_type?: "sse" | "stream"; tool: value; args?: value })`
- `s.ai.image.generate({ as?: string; model?: value; prompt: value; images?: value; aspect_ratio?: "1:1" | "2:3" | "3:2" | "3:4" | "4:3" | "4:5" | "5:4" | "9:16" | "16:9" | "21:9"; image_size?: "1K" | "2K" | "4K"; save_to_files?: "" | "public" | "private"; location?: "" | "us" | "global" | "eu" })` → as: { image: <file resource> | XanoFileRef; text: string; model: string; usage: { input_tokens?: number; output_tokens?: number } } (image is the file resource (pass it to s.storage.create_image to keep it), or the stored file value when save_to_files is "public"/"private". text is "" when the model returns none)
- `s.ai.music.generate({ as?: string; model?: value; prompt: value; negative_prompt?: value; seed?: value; save_to_files?: "" | "public" | "private"; location?: "" | "us" | "global" | "eu" })` → as: { audio: <file resource> | XanoFileRef; model: string; lyrics: string | null; description: string | null } (audio is the file resource, or the stored file value when save_to_files is set. lyrics/description are null when the model gives none (some never do))
- `s.ai.rerank({ as?: string; model?: value; query: value; documents: value; top_n?: value; location?: "" | "us" | "global" | "eu" })` → as: { results: { index: number; id: string; score: number; content: string }[]; model: string } (results best first (top_n limits them). index is the position in documents; id is the document's id, or its index as a string when it had none)
- `s.ai.speech.generate({ as?: string; model?: value; text: value; voice?: value; instructions?: value; save_to_files?: "" | "public" | "private"; location?: "" | "us" | "global" | "eu" })` → as: { audio: <file resource> | XanoFileRef; model: string; usage: { input_tokens?: number; output_tokens?: number } } (audio is the file resource, or the stored file value when save_to_files is set)
- `s.ai.speech.transcribe({ as?: string; model?: value; audio: value; language?: value; prompt?: value; location?: "" | "us" | "global" | "eu" })` → as: { text: string; model: string; usage: { input_tokens?: number; output_tokens?: number } }
- `s.ai.text.generate({ as?: string; model?: value; prompt?: value; system?: value; messages?: value; files?: value; temperature?: value; max_tokens?: value; response_format?: "text" | "json"; json_schema?: value; location?: "" | "us" | "global" | "eu" })` → as: { text: string; json: unknown; model: string; finish_reason: string | null; usage: { input_tokens?: number; output_tokens?: number } } (json is the parsed reply when response_format is "json" (throws if it does not parse), else null. finish_reason is stop | max_tokens | safety | ..., null when none. usage can be {})
- `s.ai.video.generate({ as?: string; model?: value; prompt: value; negative_prompt?: value; image?: value; last_image?: value; aspect_ratio?: "16:9" | "9:16"; resolution?: "720p" | "1080p" | "4k"; duration?: value; generate_audio?: value; timeout?: value; save_to_files?: "" | "public" | "private"; location?: "" | "us" | "global" | "eu" })` → as: { video: <file resource> | XanoFileRef; model: string; duration: number } (video is the file resource, or the stored file value when save_to_files is set. duration in SECONDS)
